# WPKG Express NG

Interface web de [WPKG](https://wpkg.org), portée sur PHP 8.5 et CakePHP 5.4.
Elle gère les hôtes, profils et paquets, et sert `hosts.xml`, `profiles.xml` et `packages.xml` aux postes Windows.

Basé sur wpkgExpress-ng (Probesys, 2013) et wpkgExpress (Brian White, 2009). Licence GPL-3.0.

Le démarrage, les tests et la bascule sont décrits dans le `README.md` à la racine du dépôt.
